Mathematical Model

🌡️ Newton's Law of Cooling (Linear Algebra Application)

T(t) = Tenv + (T0 - Tenv) × e-kt

Where: T(t) = Temperature at time t, Tenv = Ambient temp, T0 = Initial temp, k = cooling constant

📈 Linear Regression - Temperature Prediction (Algebra)

T̂ = β₀ + β₁t

Least Squares: β₁ = Σ(xᵢ - x̄)(yᵢ - ȳ) / Σ(xᵢ - x̄)²
β₀ = ȳ - β₁x̄

Using live temperature data to predict when threshold will be reached.

🔢 Matrix Representation - System State (Linear Algebra)

State Vector: S = [T₁, T₂, RPM₁, RPM₂, I₁, I₂]ᵀ

Transition Matrix maps current state to next state: S(t+1) = A × S(t) + B × u(t)

⚡ Threshold Analysis (Algebraic Inequalities)

Motor switches when: T(t) ≥ Tthreshold
Time to threshold: t* = (Tthreshold - Tcurrent) / rate
